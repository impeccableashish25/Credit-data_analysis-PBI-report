**Major Assumptions**
Dataset contains approximately 279K customer records.
Credit History Length is assumed to be measured in months.
Profile Score is treated as an internal customer quality indicator.
Risk categories are derived using a custom Weighted Risk Index.
Loan repayment history, delinquency, defaults, and credit utilization were not available.
Analysis assumes the provided customer information is accurate and complete.


**Project Limitations**
No repayment behavior available.
No default history.
No missed EMI information.
No credit card utilization data.
No interest rate information.
No debt-to-income ratio.
Weighted Risk Index is an analytical scoring model and not an industry-standard credit risk model.
Results should be interpreted as exploratory insights rather than lending decisions.
